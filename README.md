# TripNest - Airbnb-Inspired Travel Stay Platform

TripNest is a full-stack travel stay platform inspired by Airbnb. This project is being developed to build practical experience in handling the frontend, backend, and database independently.

## Features

* Create new listings
* View all listings
* View individual listing details
* Edit listings
* Delete listings
* Store listing data in MongoDB
* Image URL support
* Client-side form validation
* Server-side validation using Joi
* Custom error handling using ExpressError

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* EJS
* MongoDB
* Mongoose
* Joi
* Method-Override

## CRUD Operations

* Create - Add new listings
* Read - View listings and listing details
* Update - Edit existing listings
* Delete - Remove listings
